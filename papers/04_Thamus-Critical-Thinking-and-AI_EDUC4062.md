# Project Thamus / Thamus 项目

**How can Artificial Intelligence aid Critical Thinking skills in first-year UK university students with limited academic writing experience?**<br>
**AI 如何支持学术写作经验有限的英国大学一年级学生发展批判性思维？**

**Context / 情境**: EDUC4062 Social Contexts of Learning · MA Digital Teaching and Learning<br>
**Design status / 设计状态**: concept and learning-design proposal, April 2026<br>
**Original paper / 原文**: [Download the submitted PDF / 下载原文 PDF](04_Thamus-Critical-Thinking-and-AI_EDUC4062.pdf)

## The design problem / 设计问题

Generative AI can now search, summarise, structure and write academic prose. For a first-year student who is still learning how to read critically and build an argument, that convenience can remove the very effort through which critical thinking develops. The proposal names three connected risks: **cognitive offloading**, loss of **productive struggle**, and weak **metacognitive regulation**.

生成式 AI 已经可以搜索、总结、组织并生成学术文本。对于仍在学习批判性阅读和论证的一年级学生，便利也可能移除批判性思维赖以发展的认知努力。论文把问题聚焦为三个相互关联的风险：**认知外包**、**productive struggle（有益的认知挣扎）被削弱**，以及**元认知调节不足**。

## The learning design / 学习设计

Project Thamus is intentionally a **guide rather than a ghostwriter**. It keeps the learner doing the consequential thinking and uses AI to make the process visible, structured and reviewable.

Thamus 有意把 AI 设计成**引导者，而不是代写者**。关键的思考仍由学习者完成，AI 用来让写作过程变得可见、有结构、可回看。

| Stage / 阶段 | Learner work / 学习者任务 | Thamus support / Thamus 支持 |
| --- | --- | --- |
| 1. Purpose / 目的 | Represent the task, set a goal, name concerns / 理解任务、设定目标、说出困难 | Clarifying questions and a learner-confirmed task summary / 澄清问题与由学生确认的任务摘要 |
| 2. Exploration / 探索 | Freewrite, surface prior knowledge and gaps, plan a search / 自由写作、暴露已有知识与空缺、制定检索策略 | Prompts, constraints and feedback on the research plan / 提示、边界与研究计划反馈 |
| 3. Investigation / 调查 | Evaluate readings and connect evidence / 评价文献、连接证据 | Investigative and connective questions; editable notes / 调查问题与连接问题；可编辑笔记 |
| 4. Synthesis / 综合 | Build a thesis, outline and PEEL paragraphs / 建立论点、提纲与 PEEL 段落 | Argument ordering, reverse outlining and explanation prompts / 论证排序、反向提纲与解释提示 |
| 5. Proofreading / 校对 | Self-assess, revise and explain changes / 自评、修改并解释修改 | Nudge-based feedback and a targeted revision plan / 基于提问的反馈与针对性修改计划 |

The sequence adapts Bloom’s taxonomy while gradually increasing cognitive demand. Scaffolding fades from explicit guidance toward independent judgement, so the student’s final product is also evidence of the student’s reasoning process.

该序列借鉴修订版 Bloom 分类学，并逐步提高认知要求。支架从明确指导逐渐淡出，转向独立判断，因此最终作品同时也是学习者推理过程的证据。

## Why this matters for Learning Infrastructure / 与 Learning Infrastructure 的连接

| Infrastructure layer / 基础设施层 | Thamus example / Thamus 对应 |
| --- | --- |
| Learning context / 学习情境 | First-year HE writers with uneven academic-writing experience / 学术写作经验不均的一年级大学生 |
| Theory and constructs / 理论与构念 | Critical thinking, self-regulated learning, productive struggle, scaffolding / 批判性思维、自我调节学习、productive struggle、支架 |
| Intervention / 教学干预 | Metacognitive prompts, staged inquiry, fading support / 元认知提示、分阶段探究、逐步淡出 |
| Product pattern / 产品模式 | AI writing companion that asks before it answers / 先提问、后回应的 AI 写作伴侣 |
| Evidence and measurement / 证据与测量 | Independent reasoning, process traces, self-assessment and revision quality / 独立推理、过程记录、自评与修改质量 |

This is a design proposal, not evidence that Thamus has improved outcomes. A future pilot would need to compare independent reasoning, writing quality, learner experience and teacher workload while recording when support was used.

这是设计提案，不是 Thamus 已经改善学习结果的证据。后续试验需要同时比较独立推理、写作质量、学习体验和教师工作量，并记录支架在何时、以何种方式被使用。
